# 江山千秋万代 · 族谱辅助（第四版）

面向皇帝游戏的纯前端族谱工具。

## 第四版重点
- 多家族：不同家族独立管理、切换、增删改名
- 年号纪年：例如“永嘉二十一年 → 康熙元年”
- 下一年：只推进游戏年份，自动计算人物年龄与生死状态
- 对称族谱树：世代纵向展开，夫妻横向连接，子女向下分支
- 人物：新增、编辑、删除、父母、配偶、正室/妾室、嫡/庶、继承人、封号
- 死亡登记、JSON 导入导出、IndexedDB 本地存储、PWA 离线缓存

## 使用原则
游戏中的婚姻、生子、死亡、继承等由玩家主动记录；程序不自动生成剧情。

## 数据安全
GitHub Pages 是公开网站。应用本身把运行数据保存在当前设备浏览器 IndexedDB，但不要把真实敏感家谱数据提交到公开仓库。
