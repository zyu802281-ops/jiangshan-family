江山千秋万代·族谱辅助｜第十七版

本版重点：
- 人物卡片压缩为两行，更多操作收进「···」菜单
- 男/女使用蓝/粉色姓名标识，在世/已故使用绿/灰状态标签
- 父母首次录入后锁定；父亲、母亲均支持跨家族选择与快速搜索
- 新增子女自动带入父母
- 关系页改为「关系中心」，可搜索人物并点击亲属跳转
- 修复夫妻重复根节点渲染
- 修复自动死亡年份随寿命修改重新计算；意外死亡不受寿命重算影响
- 已故人物不再触发16岁提醒
- 已故人物享年按实际死亡年份计算
- 嫡庶排行直接显示“嫡三子/庶六子”等中文文字
- 同名新增人物二次确认
- 删除人物会提示亲子、配偶、爵位继承关联
- 撤销上一步显示具体动作

部署：建议只替换 GitHub Pages 中的 index.html 和 sw.js，不要覆盖你自己的数据文件。
