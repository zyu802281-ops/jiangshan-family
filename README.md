# 江山千秋万代 · 族谱辅助（第九版）

纯前端 PWA，适合皇帝/家族类游戏记录族谱。

## 核心功能
- 多家族独立管理，可切换家族。
- 下一年只推进游戏年份，不自动生成剧情。
- 年号纪年：支持永嘉元年、康熙元年等，并可按游戏年份切换年号。
- 人物出生、死亡只记录年份，不记录月份。
- 添加人物时自动生成默认寿命，可手动修改；死亡年份可登记。
- 配偶添加时先选所属家族，再选具体人物；也可以选择“无归属家族”，直接输入姓名并同时生成新人物。
- 对称、纵向世代族谱树。
- IndexedDB 本地存储，支持 JSON 导入/导出。
- 数据管理新增“一键清空全部人物”：清除所有人物、配偶关系和亲子关系，人物统计恢复为 0；保留家族、年号和当前游戏年份。
- 清空操作带二次确认，避免误触。
- 保留“恢复示例数据”作为测试/演示入口，与“清空全部人物”分开。

## 注意
GitHub Pages 是公开网站，不要上传真实敏感身份信息。人物数据主要保存在当前设备浏览器的 IndexedDB 中。
