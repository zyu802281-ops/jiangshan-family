江山千秋万代·族谱辅助｜第十九版

本版重点：
- 家族树改为“本人 → 配偶层 → 子女层”的分层结构。
- 正妻、妾室不再与本人横向并列，而是在本人下方统一显示。
- 每位配偶单独形成配偶分组，其对应子女显示在该配偶下方。
- 无法根据配偶确定的子女，会显示在“子女·未注明配偶”区域，避免错误归属。
- 原有家族树功能保留；关系中心继续保留，两者并列。
- 修复夫妻双方都被当作根节点造成的重复渲染。
- 人物姓名可直接点击进入编辑；人物卡继续显示第X代、嫡庶排行、年龄、家族。
- 删除人物卡上的♂/♀符号；男性姓名蓝色、女性姓名粉色。
- 保留父母锁定、跨家族父母选择、新增子女自动带入父母、死亡/意外死亡、16岁提醒、皇帝继位改元、爵位继承、备注、所有人物、一键清空、撤销、数据导入/导出与PWA离线能力。

部署：建议替换 index.html、sw.js；不要覆盖你自己的 data.json。上传后若手机仍显示旧版，请刷新页面或关闭并重新打开已添加到主屏幕的PWA。
